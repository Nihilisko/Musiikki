## Learning guide

The owner is learning to code with this project. After each larger step, add or update a chapter in `docs/opas/` (written in Finnish) and link it from `docs/opas/README.md`. Each chapter has: what the code does, why this solution and its alternatives, key code lines explained, "Muista aina" rules, and a small "Kokeile itse" exercise with answers.
